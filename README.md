# ASTER — лаборатория риска

Курсовой проект Бокой Д. В., ИТД-41. Тема: стресс-тестирование портфеля
ценных бумаг с учётом прогноза. Руководитель: Комраков В. В.

Приложение написано на C# / .NET 8 без сторонних пакетов. Два самостоятельных
вычислителя получают партии траекторий от master по настоящему TCP. HTTP-шлюз
служит TCP-клиентом master. Интерфейс — в браузере, светлая и тёмная темы.

## Быстрый запуск Windows

Установить .NET SDK 8. Открыть PowerShell в этой папке:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-Demo.ps1
```

Открыть http://127.0.0.1:8093/. Для остановки нажать Ctrl+C в терминале.
Учебный портфель уже заполнен. «Рассчитать риск» запускает 100 000 траекторий.
Настройки доступны до 500 000 траекторий и 252 шагов. Прогноз, волатильность,
корреляция и стресс задаются пользователем; цены уже приведены к одной валюте.

## Испытания

Python 3.12 нужен только для тестов и вспомогательных инструментов:

```powershell
dotnet build src/AsterRisk -c Release
py -3.12 tools/run_tests.py
py -3.12 tools/aprobation.py
```

Тесты запускают настоящие процессы C#, проверяют модель, TCP, экспорт,
отказ вычислителей, идемпотентность, отмену и сохранение. Последний протокол:
`docs/qa/test-results.json`; результаты контрольных расчётов —
`docs/qa/aprobation.json`. Повторный запуск заменит эти журналы новыми измерениями.ы

Docker: `powershell -ExecutionPolicy Bypass -File .\Start-Docker.ps1`.
Если 8093 занят, добавить `-WebPort 8094`. Сборка четырёх контейнеров и
работа при отказе вычислителя проверены: `docs/qa/docker-checks.json`.
